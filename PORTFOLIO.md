# Портфолио: Python-рутина

## Задача

Показать, что небольшая автоматизация может быть не «скриптом на коленке», а проверяемым инструментом: с планом изменений, тестами и понятными ограничениями.

## Решение

CLI `routools` с тремя командами:

- `dedupe` — поиск дублей по SHA-256, quarantine вместо удаления;
- `rename` — пакетное переименование с защитой от коллизий;
- `csv-report` — аудит CSV: строки, пустые строки, дубли, пустые ячейки.

## Результат

- 8 тестов проходят;
- демо на тестовых данных собирается одной командой;
- отчёт `demo/index.html` и скриншот `screenshots/demo.png`;
- нет внешних зависимостей;
- нет клиентских данных и секретов.

## Что показывает

- умение выбрать безопасное поведение по умолчанию;
- работу с файловой системой и CSV без лишних библиотек;
- тесты на крайние случаи;
- честную границу: это локальная утилита, а не облачный сервис.

## Стек

Python 3.10+, стандартная библиотека, unittest, HTML-отчёт.
