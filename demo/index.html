Рутина, которую можно проверить

Три команды на тестовых данных: поиск дублей, безопасное переименование и отчёт по CSV. Все изменения сначала показываются как план.

1. Дубли

SHA-256 + размер, без чтения лишних файлов.

python -m routools dedupe demo/work --apply --quarantine demo/quarantine

2. Переименование

Сортировка, проверка коллизий, dry-run по умолчанию.

python -m routools rename demo/work --pattern "doc_{n:03d}{suffix}" --apply
